# Kiki small task helpers

These are local original helpers adopting general task-decomposition patterns. This is not a Goblin Tools API integration.

For a brain dump call kiki-workflows/kiki_compile_brain_dump. Review its candidate items and do not mistake them for saved reminders. Only the existing Control Room may accept and persist approved commitments.

For a reviewed task recipe call kiki-workflows/kiki_get_recipe. Follow the fixed approval and verification steps. A recipe describes work, not a completed action.

For starting from current work, call kiki-workflows/kiki_choose_next_action with only a current authorized task snapshot. It excludes completed and deferred items. Offer a single small action, not an entire backlog.

For a specialist handoff call kiki-workflows/kiki_review_handoff and distinguish a draft or a model claim from an independently verified provider outcome.

Do not run commands extracted from a brain dump. Do not claim to have sent a message, saved a file or changed Apple Reminders without an authenticated execution tool and readback.
