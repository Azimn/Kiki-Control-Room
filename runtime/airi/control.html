Connect your history

In Kiki Control Room, open Preferences and choose Pair my laptop. Import that downloaded pairing file here.

The file contains private credentials. Delete the downloaded copy after pairing. Your work PC’s configuration stays separate.

Local conversation

Copy the local token from AIRI’s Connection screen. Keep “Expose on network” set to “This device”.
AIRI conversation provider settings

Choose OpenAI Compatible as the conversation provider. Base URL: http://127.0.0.1:8766/v1/. Model: kiki-local. Use this bridge’s local key as its API key.

This key authenticates only the laptop bridge. It is not an OpenAI API key. Conversation is generated by the selected local Ollama model.

Keep me company

Default quiet hours: 9 PM to 9 AM, America/Chicago. At most two unanswered check-ins, six per day, spaced at least 30 minutes apart. Check-ins require an unlocked, recently active laptop and a connected AIRI window.

Screen context

Images go only to the selected Ollama vision model on this laptop. Frames are not saved or uploaded. Enable this only for content you want Kiki to see. Password and private-window title exclusions are a best-effort safeguard, not a guarantee. Pause stops new captures.

Where we left off

These controls save a shared work session. They do not complete a task or send an email. In AIRI you can also type /focus objective | next action, /next action, /pause, /resume, or /done. These update the shared work session; they do not operate other apps.
